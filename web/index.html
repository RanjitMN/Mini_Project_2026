How Database Connectivity Works in this Project:

All village generation data, consumer loads, and hourly allocation results are permanently recorded via JDBC. If XAMPP's MySQL server is started, it connects to MySQL (port 3306, user root). Otherwise, it uses embedded SQLite with zero setup!

How Battery Solves the Village Problem:

At noon, surplus solar charges this battery bank. At night (after 6 PM) when solar drops to zero, the coordinator discharges stored energy to keep the Health Clinic and households powered!
